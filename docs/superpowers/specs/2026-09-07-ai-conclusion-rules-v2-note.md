# AI Conclusion Rules v2 Note

The reconstruction must distinguish between **missing pilot response** and **confirmed pilot response**. For radio-loss episodes it should explicitly evaluate: repeated critical dBm, whether VTX/video channel changed, whether altitude stayed effectively flat or climbed materially, whether communication recovered, and what mode sequence followed. Recommendations must remain counterfactual and cautious (for example, "могла бути одним із варіантів"), never asserting that a pilot action would certainly have restored the link.
